### Étape 2 — Migration V15

Fichier : `src/main/resources/db/migration/V15__create_product_images.sql`

```sql
CREATE TABLE product_images (
    id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    product_id    BIGINT NOT NULL REFERENCES products(id) ON DELETE CASCADE,
    image_url     VARCHAR(500) NOT NULL,
    alt_text      VARCHAR(255),
    is_primary    BOOLEAN NOT NULL DEFAULT FALSE,
    display_order INT NOT NULL DEFAULT 0,
    created_at    TIMESTAMP,
    updated_at    TIMESTAMP
);

CREATE INDEX idx_product_images_product_id ON product_images(product_id);
-- At most one primary image per product
CREATE UNIQUE INDEX idx_product_images_primary
    ON product_images(product_id)
    WHERE is_primary = TRUE;
```

### Étape 4 — Abstraction de stockage

**Interface** : `src/main/java/com/edgareldy/springboottutorial/storage/FileStorageService.java`

```java
public interface FileStorageService {
    /** Stores the file and returns its public URL path (e.g. "/uploads/products/uuid.jpg"). */
    String store(MultipartFile file, String subdirectory);
    /** Deletes the file identified by its URL path. Silently ignores missing files. */
    void delete(String urlPath);
}
```

**Implémentation locale** : `src/main/java/com/edgareldy/springboottutorial/storage/LocalFileStorageService.java`

- Répertoire racine configurable via `StorageProperties.uploadDir`
- Nom de fichier : `UUID.randomUUID() + "." + extension`
- Validation extension : uniquement `.jpg`, `.jpeg`, `.png`, `.webp`
- Validation Content-Type : `image/jpeg`, `image/png`, `image/webp`
- Taille max : `StorageProperties.maxFileSizeMb` (défaut 5 MB)
- Path traversal : vérifier que le chemin résolu est bien sous `uploadDir`
- Ne pas exposer le chemin système dans l'URL retournée

**Config** : `src/main/java/com/edgareldy/springboottutorial/config/StorageProperties.java`

```java
@ConfigurationProperties(prefix = "app.storage")
public record StorageProperties(
    @DefaultValue("./uploads/products") String uploadDir,
    @DefaultValue("5") int maxFileSizeMb
) {}
```

Enregistrer via `@EnableConfigurationProperties(StorageProperties.class)` sur une `@Configuration`.

### Étape 5 — Repository, Service, Mapper, DTO

**ProductImageRepository** : `findByProductId(Long productId)`, `findByProductIdAndIsPrimaryTrue(Long productId)`

**ProductImageResponse DTO** : `id`, `imageUrl` (`@JsonProperty("image_url")`), `altText` (`alt_text`),
`isPrimary` (`is_primary`), `displayOrder` (`display_order`)

**ProductImageService interface** + **ProductImageServiceImpl** :
- `addImage(Long productId, MultipartFile file, String altText, boolean isPrimary)`
  - Vérifier que le produit existe
  - Valider et stocker le fichier
  - Si `isPrimary=true`, basculer l'ancienne image principale à `false` d'abord
  - Persister `ProductImage`
  - Retourner `ProductImageResponse`
- `deleteImage(Long productId, Long imageId)`
  - Vérifier que l'image appartient bien au produit
  - Supprimer le fichier physique via `FileStorageService`
  - Supprimer l'enregistrement DB
