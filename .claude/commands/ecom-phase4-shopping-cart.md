### Étape 3 — Migration V16

Fichier : `src/main/resources/db/migration/V16__create_cart_tables.sql`

```sql
CREATE TABLE carts (
    id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id    BIGINT NOT NULL UNIQUE REFERENCES app_users(id) ON DELETE CASCADE,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

CREATE TABLE cart_items (
    id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    cart_id    BIGINT NOT NULL REFERENCES carts(id) ON DELETE CASCADE,
    product_id BIGINT NOT NULL REFERENCES products(id),
    quantity   INT NOT NULL CHECK (quantity > 0),
    CONSTRAINT uq_cart_product UNIQUE (cart_id, product_id)
);

CREATE INDEX idx_cart_items_cart_id ON cart_items(cart_id);
CREATE INDEX idx_cart_items_product_id ON cart_items(product_id);
```

### Étape 4 — Entités Cart et CartItem

**Cart.java** :
- `@OneToOne(fetch=LAZY) @JoinColumn(name="user_id") AppUser user`
- `@OneToMany(mappedBy="cart", cascade=ALL, orphanRemoval=true) List<CartItem> items`
- Audit `@CreatedDate`/`@LastModifiedDate`

**CartItem.java** :
- `@ManyToOne(fetch=LAZY) Cart cart`
- `@ManyToOne(fetch=LAZY) Product product`
- `int quantity`

### Étape 5 — DTOs

**CartItemRequest.java** : `Long productId` (`@NotNull`), `Integer quantity` (`@Positive`)
- PAS de `userId` dans le payload

**CartItemUpdateRequest.java** : `Integer quantity` (`@NotNull`, `@Positive`)

**CartItemResponse.java** : `id`, `productId` (`product_id`), `productName` (`product_name`),
`unitPrice` (`unit_price`, `BigDecimal`), `quantity`, `subtotal` (`BigDecimal`, calculé)

**CartResponse.java** : `id`, `List<CartItemResponse> items`, `BigDecimal total` (somme des subtotals)

### Étape 6 — Repositories

**CartRepository** :
- `findByUserId(Long userId)` → `Optional<Cart>`
- `findByUserUsername(String username)` → `Optional<Cart>`

**CartItemRepository** :
- `findByCartIdAndProductId(Long cartId, Long productId)` → `Optional<CartItem>`

### Étape 7 — Service

**CartService interface** :
```java
CartResponse getCart(String username);
CartResponse addItem(String username, CartItemRequest request);
CartResponse updateItem(String username, Long itemId, CartItemUpdateRequest request);
CartResponse removeItem(String username, Long itemId);
CartResponse clearCart(String username);
```

**CartServiceImpl** :
- `getOrCreateCart(AppUser user)` : charge ou crée un panier vide
- Résoudre l'utilisateur depuis `AppUserRepository.findByUsername(username)`
- `addItem` : vérifier que le produit existe ET `product.isActive() == true` ; si même produit déjà dans le panier, incrementer la quantité
- `updateItem` : vérifier que l'item appartient bien au panier de cet utilisateur
- `removeItem` : idem
- Calculer `subtotal = item.quantity * product.unitPrice` (BigDecimal)
- `total` = somme des subtotals

**CartMapper** : `Cart` → `CartResponse`, `CartItem` → `CartItemResponse`

### Étape 8 — Contrôleur

**CartController** : `@RequestMapping("/api/v1/cart")`

```
GET    /api/v1/cart                   — getCart
POST   /api/v1/cart/items             — addItem (body: CartItemRequest)
PATCH  /api/v1/cart/items/{itemId}    — updateItem (body: CartItemUpdateRequest)
DELETE /api/v1/cart/items/{itemId}    — removeItem
DELETE /api/v1/cart/items             — clearCart
```

Résoudre l'utilisateur depuis `@AuthenticationPrincipal UserDetails userDetails` → `userDetails.getUsername()`.
**Ne jamais recevoir `userId` dans les payloads.**

### Étape 9 — Sécurité

Dans `SecurityConfig`, protéger `/api/v1/cart/**` avec `hasRole("USER")`.
